# Tracky website

This is a dependency-free static landing page for Tracky's React component library and analytics SDK direction. The SDK is in the current scaffold; the initial component source is in `registry/` and is not installable yet. Open `index.html` directly or serve this folder locally, for example with `python -m http.server 8000`, then visit `http://localhost:8000`.
