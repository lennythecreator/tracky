## What a live example shows

Each example below is the file `tracky add` installs, rendered with the SDK provider. Interact with a control and the panel under it reports the event the primitive sent.

The provider points at a reserved endpoint that this page answers itself, so nothing leaves the browser. Page-wide capture stays off: a primitive reports its one documented action and nothing else.

## Button

<Example name="button" />

`Button` sends `button · activate` on click, and on Enter or Space through the native button. The label and the `analyticsName` are not part of the event beyond the name you pass.

## Checkbox

<Example name="checkbox" />

`Checkbox` sends `checkbox · toggle` when the checked state changes. Space toggles the focused checkbox; the checked state stays in your app.

## Switch

<Example name="switch" />

`Switch` is a native checkbox with `role="switch"`, so Space toggles it and the event is still `switch · toggle`.

## Select

<Example name="select" />

`Select` sends `select · change` when the choice changes. The selected option is never sent.

## Source

Every example prints the file it rendered. The demo and the listing come from the same import, so a change to one cannot leave the other behind.

<Callout variant="note" title="Nothing is collected here">
  The docs do not read a field value, a keystroke, or any page text, and they
  make no request of their own. The preview only shows what the SDK would send.
</Callout>
