## Install

```sh
npx tracky add switch
```

`Switch` requires the `utils` item for `cn()` and lists `tracky` as a dependency. The package is not published yet, so install both once a release exists.

Space or a click flips the switch and sends one toggle. The event does not include the new state.

## Action

`Switch` sends `switch · toggle` through the nearest provider after your `onChange` runs. The event carries `{ name: 'switch', action: 'toggle' }` and, when set, `context: { name: analyticsName }`.

The checked value, the label, and any prop are never read or sent. The control's thumb and colour change in your app; neither is part of the event.

## Keyboard and screen readers

- Space toggles the focused switch.
- The native checkbox state is exposed with `role="switch"`, so assistive technology announces on or off.
- Tab reaches the switch unless it is disabled.
- Focus shows a `focus-visible` ring with the ring offset against the background.
- Disabled uses the native attribute, a muted track, and reduced opacity.
- `aria-invalid="true"` adds a destructive border and ring.
