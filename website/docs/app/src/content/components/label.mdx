## Install

```sh
npx tracky add label
```

`Label` requires the `utils` item for `cn()` and lists no analytics dependency. The package is not published yet, so install `utils` alongside it once a release exists.

## Action

`Label` sends no component event and does not render `data-tracky-component`. It has no analytics code, so clicking or focusing the label cannot reach the SDK from this component.

## Keyboard and screen readers

- A native `label` associated with a control names that control for assistive technology.
- Clicking the label moves focus to the control; no JavaScript is involved.
- Focus styling belongs to the control, not the label.
- The label is not focusable on its own, so it adds no tab stop.

Use `htmlFor` with a matching `id`, or wrap the control inside the label. For a control without visible text, give the control an `aria-label` rather than leaving it unnamed.

## Theme tokens

`text-foreground`, `font-sans`, and the inherited font size and weight used by the field it names.
