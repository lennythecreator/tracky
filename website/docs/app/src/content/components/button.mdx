## Install

```sh
npx tracky add button
```

`Button` requires the `utils` item for `cn()` and lists `tracky` as a dependency. The package is not published yet, so install `utils` alongside it once a release exists.

The caller's `onClick` runs first. If it calls `event.preventDefault()`, the button sends nothing, because the interaction was cancelled.

## Action

`Button` sends `button · activate` through the nearest provider. Enter and Space produce the same action as a pointer click, because they are the native button's activation. The event carries the component object `{ name: 'button', action: 'activate' }` and, when you set it, `context: { name: analyticsName }`.

No label, child text, `aria-label`, `type`, variant, size, or other prop is read or sent.

## Keyboard and screen readers

- Tab reaches every enabled button; disabled buttons are skipped.
- Enter and Space activate the focused button.
- Focus shows a `focus-visible` ring built from `ring-ring` and `ring-offset-background`.
- Disabled uses the native attribute, so assistive technology reports it and the button is not focusable.
- The label is yours to supply, with visible text or `aria-label`.
