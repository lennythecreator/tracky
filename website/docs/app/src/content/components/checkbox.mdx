## Install

```sh
npx tracky add checkbox
```

`Checkbox` requires the `utils` item for `cn()` and lists `tracky` as a dependency. The package is not published yet, so install both once a release exists.

## Action

`Checkbox` sends `checkbox · toggle` through the nearest provider after your `onChange` runs. The event carries `{ name: 'checkbox', action: 'toggle' }` and, when set, `context: { name: analyticsName }`.

The `checked` value, the label, and any prop are never read or sent. Use `analyticsName` when several rendered instances should group together.

## Keyboard and screen readers

- Space toggles the focused checkbox; that is the native behavior.
- The native `checked` state is exposed to assistive technology, so the control announces on and off.
- Tab reaches the checkbox unless it is disabled.
- Focus shows a `focus-visible` ring; disabled uses the native attribute.
- `aria-invalid="true"` switches the border and ring to `destructive`.
