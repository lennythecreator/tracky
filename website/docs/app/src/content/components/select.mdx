## Install

```sh
npx tracky add select
```

`Select` requires the `utils` item for `cn()` and lists `tracky` as a dependency. The package is not published yet, so install both once a release exists.

## Action

`Select` sends `select · change` through the nearest provider after your `onChange` runs. The event carries `{ name: 'select', action: 'change' }` and, when set, `context: { name: analyticsName }`.

The selected value, the option text, the label, and any prop are never read or sent.

## Keyboard and screen readers

- The native select keeps its own keyboard model: arrow keys move through options, Home and End jump, and typing selects by prefix.
- The current option is exposed to assistive technology by the browser.
- Tab reaches the select unless it is disabled.
- Focus shows a `focus-visible` ring; disabled uses the native attribute.
- `aria-invalid="true"` switches the border and ring to `destructive`; connect error text with `aria-describedby`.
