## What this site covers

The docs cover the analytics SDK and the component library that the `tracky` CLI installs as source. They do not describe a hosted service: your endpoint receives every event, and it owns validation, storage, retention, and access.

This scaffold ships two pages. The sidebar on the left is authored by `meta.json` in each content folder, and the list on the right is built from the headings on the page you are reading. The pager at the bottom follows the same order.

## Where to start

- If you are choosing what to collect, start with the capture switches guide.
- If you are wiring an endpoint, the SDK quick start in the repository README is the shortest path to a first event.
- If you are adding a primitive, read the component conventions before you write a file.

## What the docs do not do

The pages send nothing. This app mounts no analytics provider and makes no request of its own, so reading the docs is not a visit to your endpoint.
