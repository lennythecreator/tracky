What the analytics SDK does.

Call analytics.track() for product events. Enable page views or interaction metadata only when you need them.

Opt in to automatic capture

Enable page views and basic interaction metadata when you need them. Tracky never reads field values or typed text.

Send events in batches

Tracky buffers events and retries temporary failures a limited number of times. Your endpoint handles durable storage.

Know what Tracky sends.

Each event includes a name, ISO timestamp, relative route, context, and random tab-scoped session ID. Tracky sends batches as JSON to your endpoint.

Start with the analytics SDK.

Wrap a client-side part of your app, set your endpoint, then call track() for the events you want to measure.

analytics.tsx
import type { ReactNode } from 'react';
import { AnalyticsProvider, useAnalytics } from 'tracky';

function ExportButton() {
  const analytics = useAnalytics();
  return (
    <button onClick={() => analytics.track('report_exported', { format: 'csv' })}>
      Export report
    </button>
  );
}

export function AppAnalytics({ children }: { children: ReactNode }) {
  return (
    <AnalyticsProvider endpoint="https://your-api.example.com/events"
      options={{ capturePageViews: true }}>
      {children}
    </AnalyticsProvider>
  );
}

Tracky is in early development. The SDK API may change, and the package is not published yet.
