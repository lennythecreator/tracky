# Claude Code instructions

Before making changes, read [`AGENTS.md`](./AGENTS.md), [`product.md`](./product.md), and [`README.md`](./README.md). `AGENTS.md` contains the shared repository and privacy rules; `product.md` defines the product scope and distinguishes current behavior from future proposals. When writing developer-facing content, also follow [`WRITING.md`](./WRITING.md). Follow these files for project conventions, event-data boundaries, and verification commands.

Keep changes focused on the Tracky React SDK. Do not treat the future licensing concept as an implemented requirement, and do not collect user-entered values or add an undisclosed telemetry destination.
